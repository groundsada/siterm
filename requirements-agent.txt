# opentelemetry-sdk >=1.39.1 is a correctness floor, not just currency.
# SiteRM builds the TracerProvider and BatchSpanProcessor before forking: the
# daemons double-fork in Daemonizer.daemonize(), and the frontend runs gunicorn
# with --preload. The exporter's background thread does not survive fork(). The
# SDK's shared BatchProcessor calls os.register_at_fork(after_in_child=...) to
# rebuild it in the child; without that, children queue spans forever and export
# nothing, silently. Re-verify before relaxing this pin.

opentelemetry-sdk>=1.39.1,<1.40.0
